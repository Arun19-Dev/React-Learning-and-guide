Topic 1

DOM vs Virtual DOM (Sema Speed!)

React oda super power eh adhu use panra Virtual DOM dhan. Aana adhukku munnadi, 'DOM' na ennanu therinjippom.

💀 Real DOM na enna? (Document Object Model)

DOM na namma website oda Skeleton (Elumbu Koodu) mari. Browser namma HTML code-ah oru 'Tree' structure-ah mathum. Idhula oru chinna prechana irukku: Real DOM romba slow! Oru chinna text maaruna kooda, whole page-um refresh aagum (re-paint aagum).

👻 Virtual DOM na enna?

React enna pannuchu na, Real DOM ku oru "Duplicate Copy" create panniduchu. Adhudhan Virtual DOM.

  • Eppa namma page-la oru data maarudho, React udane adha Virtual DOM-la pottu paakum.
  • Pudhu Virtual DOM-um, Pazhaya Virtual DOM-um compare panni, "Enna maari irukku?" nu kandu pudikkum (Idhuku peru Diffing).
  • Apparam, Real DOM-la enga maarucho andha specific edatha mattum update pannum! (Idhuku peru Reconciliation).
⚡
Simple ah sollanumna:

Oru sevuthula (wall) oru chinna kirukkal (scratch) irundha, Real DOM full sevuthayum idichitu pudhusa kattum. Aana Virtual DOM andha kirukkal irukka edathula mattum paint adikkum. Idhunala dhan React sema fast!

🎬 Virtual DOM Animation Parunga:

Kezha irukka "Change Color" button-ah amukkunga. Full box maarama, ulla irukka circle mattum eppadi maarudhu nu parunga.

Naan dhan Real DOM (Website)

Topic 2

Components & Adhoda Benefits

Component-ngradhu Lego Blocks mari. Oru periya veedu katta eppadi செங்கல் (bricks) thevayo, adhe mari oru web page-ah kutti kutti pieces-ah pirikkuradhu dhan Components.

Normal ah HTML, CSS, JS nu thani thaniya ezhudhuvom. Aana React-la idhu moonayum sethu oru Custom HTML Tag (example: <MyButton />) aah mathiduvom.

🌟 Components oda Benefits (Yen idhu ivlo famous?):

  • ♻️ Reusability (Thirumba use panlam): Oru thadava code ezhudhina podhum. Amazon-la irukka 'Add to Cart' button mari, enga venumo anga just <CartButton /> nu potukalam. Copy-paste thevai illa!
  • 🛠️ Maintainability (Easy-ah fix panlam): Oru vela Header-la oru bug vandha, full code-ah theda thevai illa. Header.jsx file-ah mattum open panni easy-ah fix pannidalam.
  • 📖 Readability (Padikka easy): Code paaka romba clean-a irukkum. Yaaru vandhu paathalum, "Oh, idhu Header, idhu Footer" nu udane puriyum.

Topic 3

Props vs State (Enna difference?)

React padikkum podhu idhu rendu dhan romba mukkiyam. Easiya purinjikalam vanga:

🧬 Props (Genetics)

Props na Properties. Oru amma/appa kitta irundhu kulandhaiku varum DNA mari idhu. Idhava matha mudiyadhu (Read-only). Parent component tharadha child component vangi display pannum avalodhan.

🎭 State (Mood / Feeling)

State na unga current mood mari. Ippo neenga happy-a irukalam, rendu nimisham kalichu pasi vandha sad aagiduvinga. State-a eppo vena mathalam. State maaruna, React udane andha edatha pudhusa draw pannum (re-render).
