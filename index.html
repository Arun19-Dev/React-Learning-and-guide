CHAPTER 1

What is React?

React is a JavaScript library made by Facebook (now Meta). It helps you build user interfaces — the part of a website or app that people see and click on. Think of it like a set of building blocks for making web pages.

Why Do Developers Love React?

Before React, building big web apps was really hard. When you changed one thing, you had to update the whole page. React fixed that. Here are the core ideas that make React special:

🧩

Components

Break your page into small, reusable pieces. A button, a menu, a card — each one is a component. Build once, use everywhere.

⚡

Virtual DOM

React keeps a lightweight copy of the page in memory. When something changes, React figures out the smallest update needed — making your app super fast.

🔄

One-Way Data Flow

Data flows from parent to child, like water flowing downhill. This makes your app easy to understand and debug.

📦

JSX Syntax

Write HTML-like code right inside JavaScript. It looks familiar and makes building UIs feel natural and simple.

CHAPTER 2

Installation & Setup

Before you can build with React, you need two tools on your computer: Node.js and npm (Node Package Manager). Let's set them up step by step.

What Are Node.js and npm?

🟢

Node.js

Node.js lets you run JavaScript outside the browser — on your computer. React's build tools need Node.js to work.

📦

npm

npm is like an app store for JavaScript code. It comes free with Node.js. You use it to download React and other tools.

Step-by-Step Installation

1

Download Node.js

Go to nodejs.org and click the LTS (Long Term Support) button. This gives you the most stable version.

2

Run the Installer

Open the downloaded file and follow the installer. Keep all the default settings — just click Next until it finishes.

3

Check the Installation

Open your Terminal (Mac) or Command Prompt (Windows) and type these commands:

Terminal 
node --version
npm --version

You should see version numbers like v20.10.0 and 10.2.0. If you see them, you're all set!

✅
Quick Tip

Always download the LTS version of Node.js. It's the most tested and stable. The "Current" version has newer features but might have bugs.

Code Editor — VS Code

You'll also need a code editor. We recommend Visual Studio Code (VS Code) — it's free, powerful, and most React developers use it.

1

Download VS Code

Visit code.visualstudio.com and download it for your operating system.

2

Helpful Extensions

Install these VS Code extensions to make React development easier:

  • ES7+ React Snippets — gives you shortcuts for React code
  • Prettier — automatically formats your code to look clean
  • Auto Rename Tag — renames both the opening and closing HTML tag

CHAPTER 3

Creating Your First React Project

Now let's build something! React gives you a tool called Vite (pronounced "veet") to create a new project with one command. It sets up everything for you.

Create a Project with Vite

Open your terminal and run this command:

Terminal 
# Create a new React project called "my-first-app"
npm create vite@latest my-first-app -- --template react

# Move into the project folder
cd my-first-app

# Install all the packages React needs
npm install
📝
What Just Happened?

npm create vite@latest downloads and runs the Vite project creator. The --template react flag tells it to set up a React project. Then npm install downloads all the code React needs to work.

Understanding Your Project Structure

After creating the project, you'll see these folders and files. Let's understand what each one does:

Project Structure 
my-first-app/
├── node_modules/      ← Downloaded packages (don't touch this)
├── public/            ← Static files like images
├── src/               ← YOUR CODE GOES HERE ⭐
│   ├── App.jsx        ← The main component
│   ├── App.css        ← Styles for App
│   ├── main.jsx       ← The entry point (starts React)
│   └── index.css      ← Global styles
├── index.html         ← The HTML page
├── package.json       ← Project info & list of packages
└── vite.config.js     ← Vite's settings

Your First React File — App.jsx

This is the heart of your app. Let's look at what's inside:

src/App.jsx 
// This is a React component — a reusable piece of your page
function App() {
  return (
    <div>
      <h1>Hello, React! 🎉</h1>
      <p>This is my first React app.</p>
    </div>
  );
}

export default App;
🔑
What is JSX?

The HTML-looking code inside the return() is called JSX. It's not real HTML — it's a special syntax that React turns into real HTML for the browser. You write what looks like HTML, but it's actually JavaScript!

CHAPTER 4

Running a React Application

You've created a project — now let's see it in the browser! React comes with a built-in development server that shows your app and updates it instantly when you make changes.

Start the Development Server

Terminal 
# Make sure you're inside your project folder
cd my-first-app

# Start the development server
npm run dev

After running this, you'll see a message like:

Terminal Output 
  VITE v5.0.0  ready in 300 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.1.5:5173/
  ➜  press h + enter to show help

Open your browser and go to http://localhost:5173. You'll see your React app running! 🎉

🎬 Hot Module Replacement (HMR)

One of the best features of React development: when you save a file, the browser updates immediately — no manual refresh needed. This is called Hot Module Replacement.

Important Commands to Remember

Command What It Does
npm run dev Starts the development server (for building)
npm run build Creates the final version for your real website
npm run preview Preview the built version locally
Ctrl + C Stops the development server
⚠️
Common Mistake

If you see an error saying "port already in use", it means another server is running. Press Ctrl + C to stop it, or use a different port by running npm run dev -- --port 3000.

CHAPTER 5

Creating & Working with Components

Components are the building blocks of every React app. Think of them like LEGO pieces — small, reusable parts that fit together to build something big. Let's learn how they work!

What is a Component?

A component is just a JavaScript function that returns JSX (the HTML-like code). Here's the simplest component you can make:

src/Greeting.jsx 
// A simple component — it's just a function!
function Greeting() {
  return <h2>Hello there! 👋</h2>;
}

export default Greeting;
📐
Rules for Components

1. The name must start with a capital letter (like Greeting, not greeting).
2. It must return JSX — some UI to display.
3. Save it in a .jsx file.

Props — Passing Data to Components

Props (short for "properties") let you send data into a component, like passing an argument to a function. This makes components reusable with different data.

src/UserCard.jsx 
// This component takes "name" and "role" as props
function UserCard({ name, role }) {
  return (
    <div className="card">
      <h3>{name}</h3>
      <p>{role}</p>
    </div>
  );
}

// Use it like this:
<UserCard name="Alice" role="Developer" />
<UserCard name="Bob" role="Designer" />

State — Making Components Interactive

State is data that can change over time. When state changes, React automatically re-renders (redraws) the component. This is how you make things interactive!

src/Counter.jsx 
import { useState } from 'react';

function Counter() {
  // useState gives us: [currentValue, functionToUpdateIt]
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>Count: {count}</h2>
      <button onClick={() => setCount(count + 1)}>
        Add One
      </button>
    </div>
  );
}

A Complete Component Example

Let's put props and state together in one component — a greeting card with a toggleable message:

src/GreetingCard.jsx 
import { useState } from 'react';

function GreetingCard({ name }) {
  const [showMessage, setShowMessage] = useState(false);

  return (
    <div style={{ padding: '20px', border: '1px solid #ddd', borderRadius: '12px' }}>
      <h2>Hi, {name}! 👋</h2>
      <button onClick={() => setShowMessage(!showMessage)}>
        {showMessage ? 'Hide' : 'Show'} Message
      </button>
      {showMessage && <p>Welcome to the world of React! 🚀</p>}
    </div>
  );
}

export default GreetingCard;

CHAPTER 6

Understanding React Libraries

React alone is great for building UIs. But real-world apps need more — routing between pages, fetching data from servers, managing forms, and more. That's where libraries come in.

What is a Library?

A library is pre-written code someone else made that you can use in your project. Instead of building everything from scratch, you install a library and use it. Think of it like ordering takeout instead of cooking every meal yourself.

🧠
Library vs Framework

A library (like React) gives you tools to use when YOU need them — you're in control. A framework (like Angular) tells YOU how to build — it's in control. React is a library because it lets you decide how to structure your app.

Essential React Libraries

Here are the most popular and useful libraries for React apps:

Routing

React Router

Lets your app have multiple pages. Users can go from a Home page to an About page without reloading the whole site.

npm install react-router-dom
State

Zustand

A tiny, simple way to share data between many components. Much easier to learn than Redux!

npm install zustand
HTTP

Axios

Makes it easy to get data from servers (APIs). Send requests and handle responses with clean, simple code.

npm install axios
UI

Material UI (MUI)

Beautiful, ready-made components (buttons, modals, forms) that follow Google's Material Design. Saves hours of styling work.

npm install @mui/material @emotion/react @emotion/styled
Forms

React Hook Form

Handles form input, validation, and errors with minimal code. Super fast and lightweight.

npm install react-hook-form
Data

TanStack Query

Fetches, caches, and syncs server data automatically. No more manual loading states — it handles everything.

npm install @tanstack/react-query

How to Find & Choose Libraries

The npm registry has over 2 million packages. Here's how to pick the right one:

Check This Why It Matters
⭐ GitHub Stars More stars = more developers trust and use it
📅 Last Updated If it hasn't been updated in years, it might be abandoned
📥 Weekly Downloads High downloads mean it's actively used in production apps
📖 Documentation Good docs = easier to learn and use
📦 Bundle Size Smaller is better — big libraries slow down your app

Importing & Using Libraries

You know what libraries are — now let's learn how to actually install them and use them in your code. It's a simple 3-step process: install → import → use.

🎬 The Import Flow

Here's how code flows from an npm package into your component:

📦 How Importing Works
npm
Package
→
node_modules/
→
import in
Your Code
→
Use in
Component

Step 1 — Install the Library

Use npm install (or the shortcut npm i) in your terminal:

Terminal 
# Install one library
npm install axios

# Install multiple at once
npm install react-router-dom zustand

# Shortcut — "i" means "install"
npm i axios

Step 2 — Import in Your Code

At the top of your file, use the import keyword to bring in the library:

Default import — the library exports one main thing:

JSX 
// Default import — you can name it anything
import axios from 'axios';

// Use it
const response = await axios.get('https://api.example.com/data');

Named import — pick specific pieces from a library:

JSX 
// Named import — use curly braces { }
import { BrowserRouter, Route, Routes } from 'react-router-dom';

// React's own hooks are also named imports
import { useState, useEffect } from 'react';

Both — default and named together:

JSX 
// Default + named imports from the same library
import React, { useState, useEffect } from 'react';

Step 3 — Use in Your Component

Here's a complete, real-world example using Axios to fetch data from an API:

src/UserList.jsx 
import { useState, useEffect } from 'react';
import axios from 'axios';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // Fetch users when the component first appears
    axios.get('https://jsonplaceholder.typicode.com/users')
      .then(response => {
        setUsers(response.data);
        setLoading(false);
      })
      .catch(error => {
        console.error('Error:', error);
        setLoading(false);
      });
  }, []); // [] means: run only once

  if (loading) return <p>Loading users...</p>;

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

export default UserList;

Importing Your Own Components

You can also import components you made yourself. Use relative paths (starting with ./ or ../):

src/App.jsx 
// Importing your own components
import Header from './components/Header';
import UserCard from './components/UserCard';
import Footer from './components/Footer';

// Importing a CSS file
import './App.css';

function App() {
  return (
    <div>
      <Header />
      <UserCard name="Alice" role="Developer" />
      <Footer />
    </div>
  );
}

export default App;
💡
Import Rules Cheat Sheet

📦 npm packages: import axios from 'axios' — no path, just the name
📁 Your own files: import Header from './Header' — use ./ for current folder
🎨 CSS files: import './styles.css' — no variable name needed

Example — Using React Router for Pages

src/App.jsx — with React Router 
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';
import Home from './pages/Home';
import About from './pages/About';

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/about">About</Link>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}
