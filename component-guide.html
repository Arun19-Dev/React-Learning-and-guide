Building a Complete React App

A step-by-step masterclass on building a React application from scratch using a clean, reusable, component-based architecture with separate Header, Body, and Footer components.

Part 1

Project Requirements & Structure

We are going to build a React application with three separate components: Header, Body, and Footer. We will then integrate them into our main App.jsx file.

Complete Project Structure

Before writing code, it's essential to understand how our files will be organized. Here is the exact folder structure we will create:

Directory Structure 
my-react-app/
├── public/                 <-- Static files (like favicons)
├── src/                    <-- All your React code goes here
│   ├── components/         <-- Folder for reusable components
│   │   ├── Header.jsx      <-- Header component logic
│   │   ├── Header.css      <-- Header component styles
│   │   ├── Body.jsx        <-- Body component logic
│   │   ├── Body.css        <-- Body component styles
│   │   ├── Footer.jsx      <-- Footer component logic
│   │   └── Footer.css      <-- Footer component styles
│   ├── App.jsx             <-- The main parent component
│   ├── App.css             <-- App layout styles
│   ├── index.css           <-- Global CSS rules
│   └── main.jsx            <-- React entry point
├── package.json            <-- Project dependencies
└── vite.config.js          <-- Vite bundler configuration
Step 1

Create the React Project

First, make sure you have Node.js installed (download the LTS version from nodejs.org). Node.js allows us to run React's build tools.

Open your Terminal or Command Prompt and run the following commands sequentially:

Terminal 
# 1. Create a React project using Vite
npm create vite@latest my-react-app -- --template react

# 2. Navigate into the new project directory
cd my-react-app

# 3. Install required dependencies
npm install

# 4. Start the local development server
npm run dev

Now, open http://localhost:5173 in your browser to see the default Vite starter page. Keep the terminal running in the background while you code!

Step 2

Create the Header Component

A React component is simply a JavaScript function that returns JSX (HTML-like syntax). We separate our UI into components to keep code clean and reusable.

1. Create the Component File

File to create: src/components/Header.jsx

src/components/Header.jsx 
function Header() {
  // Returns JSX to define the UI structure
  return (
    <header className="header-container">
      <h1>My First React App</h1>
      <nav>
        <ul className="nav-links">
          <li><a href="#home">Home</a></li>
          <li><a href="#about">About</a></li>
          <li><a href="#contact">Contact</a></li>
        </ul>
      </nav>
    </header>
  );
}

// Export the component so it can be imported elsewhere
export default Header;

2. Create the Stylesheet

File to create: src/components/Header.css

src/components/Header.css 
/* Styles specifically for the Header component */
.header-container {
  background-color: #282c34;
  color: white;
  padding: 20px;
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.header-container h1 {
  margin: 0;
  font-size: 1.5rem;
}

.nav-links {
  list-style: none;
  display: flex;
  gap: 20px;
  margin: 0;
  padding: 0;
}

.nav-links a {
  color: #61dafb;
  text-decoration: none;
  font-weight: bold;
}

.nav-links a:hover {
  color: white;
}

Notice how we use className in JSX instead of class. Since JSX is basically JavaScript, and class is a reserved JS keyword, React requires className.

Step 3

Create the Body Component

The Body component will hold our main page content. Unlike the header, we'll wrap this in a semantic <main> HTML tag.

1. Create the Component File

File to create: src/components/Body.jsx

src/components/Body.jsx 
function Body() {
  return (
    <main className="body-container">
      <h2>Welcome to Component-Based Architecture</h2>
      <p>
        React allows us to break our user interface down into smaller, 
        reusable pieces called components. Right now, you are looking at the 
        <strong> Body </strong> component!
      </p>
      
      <div className="card-grid">
        <div className="card">
          <h3>Fast</h3>
          <p>React is incredibly fast thanks to the Virtual DOM.</p>
        </div>
        <div className="card">
          <h3>Reusable</h3>
          <p>Build a component once, use it everywhere.</p>
        </div>
      </div>

}

export default Body;

Step 4

Create the Footer Component

Finally, we'll build the footer. Here we will inject real JavaScript logic (getting the current year) directly into the JSX using curly braces {}.

1. Create the Component File

File to create: src/components/Footer.jsx

src/components/Footer.jsx 
function Footer() {
  // JavaScript logic written before the return statement
  const currentYear = new Date().getFullYear();

  return (
    <footer className="footer-container">
      {/* We use {} to evaluate JavaScript variables inside JSX */}
      <p>&copy; {currentYear} My React App. All rights reserved.</p>
      <p>Built with ❤️ and React.</p>
    </footer>
  );
}

export default Footer;

2. Create the Stylesheet

File to create: src/components/Footer.css

src/components/Footer.css 
.footer-container {
  background-color: #282c34;
  color: white;
  text-align: center;
  padding: 20px;
  margin-top: auto; /* Keeps it at the bottom */
}

.footer-container p {
  margin: 5px 0;
  font-size: 0.9rem;
}
Step 5

Integrate Components into App.jsx

Now we bring our three independent pieces into the central parent component, App.jsx.

File to update: src/App.jsx

src/App.jsx 
// 1. Import all component CSS files
import './App.css';
import './components/Header.css';
import './components/Body.css';
import './components/Footer.css';

// 2. Import the React components
import Header from './components/Header';
import Body from './components/Body';
import Footer from './components/Footer';

function App() {
  return (
    <!-- Wrap everything in a main container for layout -->
    <div className="app-layout">
      {/* 3. Render the components in the correct order */}
      <Header />
      <Body />
      <Footer />
    </div>
  );
}

export default App;

Notice how we use component tags like <Header />. These are self-closing tags. When React sees them, it executes the code from the imported file and renders the resulting UI here.

Step 6

Update App.css and index.css

We need to apply global styling to make the app look clean and responsive.

1. App Layout Styling

File to update: src/App.css

src/App.css 
/* App-level layout */
.app-layout {
  display: flex;
  flex-direction: column;
  min-height: 100vh; /* 100% of the screen height */
}

/* Make the layout responsive on smaller screens */
@media (max-width: 600px) {
  .card-grid {
    flex-direction: column;
    align-items: center;
  }
}

2. Global CSS Reset

File to update: src/index.css

src/index.css 
/* Global Reset */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  background-color: #f4f4f9;
  color: #333;
}

We separate our CSS to avoid duplicated styles. index.css is for global changes, while component files only style their own elements.

Step 7

Check main.jsx

This file bridges React with the actual browser. You don't need to change anything here.

File: src/main.jsx

src/main.jsx 
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'
import './index.css'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)

It selects the empty <div id="root"> in index.html and injects the <App /> component inside it, triggering the entire rendering flow.

Concept

The Import & Export System

JavaScript uses an import/export system to share code between files.

1. Default Export & Import

If a file exports exactly ONE main thing, use export default. When importing a default, you do not use curly braces.

// In Header.jsx
export default Header;

// In App.jsx
import Header from './components/Header';

2. Named Export & Import

If a file exports multiple things, use export before the function. When importing, you MUST use curly braces and exact names.

// In Utilities.js
export function calculate() {}
export function format() {}

// In App.jsx
import { calculate, format } from './Utilities';
⚠️
Common Mistakes

• Incorrect path: import Header from './Header' (Forgot the components/ folder).
• Wrong capitalization: Trying to import header.jsx instead of Header.jsx.
• Forgot to export: React throws a module not found error.
• Imported but not rendered: If you import Header but forget to type <Header /> in the return block, it won't show on screen!

Final

Application Flow & Testing Checklist

Complete Rendering Flow

Here is how React assembles the final page:

main.jsx (The Entry Point)
   ↓ 
   It mounts the <App /> component to the browser.
   ↓
App.jsx (The Parent)
   ↓
   App says, "I need to display a Header, a Body, and a Footer."
   ├── Header.jsx (Draws the top navigation and logo)
   ├── Body.jsx   (Draws the main content and cards)
   └── Footer.jsx (Draws the copyright at the bottom)

Final Testing Checklist

Before celebrating, verify the following:

  • ✅ The application runs without errors (npm run dev is active).
  • ✅ The Header appears at the top with a dark background.
  • ✅ The Body appears in the middle with your two styled cards.
  • ✅ The Footer appears firmly at the bottom of the screen.
  • ✅ All CSS files are loaded and applied correctly.
  • ✅ The layout is responsive (cards stack on mobile screens).
  • ✅ Check your browser Console (Right Click > Inspect > Console) for any red errors.
